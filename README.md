# iemarjay.com

Personal brand and portfolio project for Emmanuel Joseph (@iemarjay).

## Structure

- **website/** - Next.js portfolio and blog site
- **content/** - Blog posts and copy drafts
- **docs/** - Brand strategy and planning documents

## Quick Start

```bash
cd website
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
