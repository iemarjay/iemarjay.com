## The Origin Story

### The $10k Webhook Replay Attack

**What happened**: Building Panelsuite (a payment platform for a client) with Korapay integration. Attackers replayed webhook notifications 2-6 times before system could check duplicates. Single deposit credited multiple times.

**Cost**: Nearly $10,000 in client losses.

**The connection**: Later found signature replay vulnerability in own smart contracts — exact same bug class. The methodology built from that failure caught it.

**Narrative arc**:
> "I learned about replay attacks the hard way — a webhook vulnerability cost my client $10k. That failure drove me to build systematic security checks. When I later audited my own smart contracts, I found the same class of bug: a signature that could be replayed across chains."
